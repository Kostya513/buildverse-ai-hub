

# BUILDVERSE — AI-управляемая строительная экосистема

## Обзор
Статичная одностраничная платформа с glassmorphism-дизайном на изумрудном градиентном фоне. Все данные — моковые, без бэкенда.

---

## 1. Визуальная тема
- Фон: градиент `#0a3d62 → #0f4c75 → #1a5a8c` на всю страницу
- Стеклянные карточки: `backdrop-filter: blur(10px)`, полупрозрачный белый фон, мягкие тени и glow-эффект по краям
- Шрифты: белый текст на тёмных поверхностях, контрастный на светлых
- Neumorphism + glassmorphism стилистика

## 2. Хедер (fixed, стеклянный)
- Логотип **BUILDVERSE** слева (жирный шрифт)
- Кнопка «Вход/Регистрация» справа
- Гамбургер-меню → выдвижная боковая панель с пунктами: О нас, Настройки, Тарифы (Freemium/Pro/Бизнес), Партнёры, Конфиденциальность, Помощь

## 3. Трёхколоночный Layout (desktop)
### Левая панель (25%) — Лаунчер
10 вертикальных стеклянных плиток с иконками и подписями:
- Геоинтеллект, Мои проекты, Стройнет, Инвестиции, Маркетплейс, Подрядчики, Смета, СтройМакс, Цифровой паспорт, Уведомления
- Hover-эффект: приподнимание + glow
- Клик по плитке меняет содержимое центральной зоны

### Центральная зона (50%)
- По умолчанию — экран «Геоинтеллект» с картой-заглушкой и табами (Климат, Грунт, Рельеф, Экосистема, Солнце)
- Кнопка «Создать проект»
- Фиксированный чат-бар внизу: кнопки прикрепления файла, голоса, поле ввода, отправка
- При переключении плиток — fade-in анимация нового контента

### Правая панель (25%) — Контекстный сайдбар
- AI-Ассистент СтройМакс (мок-чат)
- Блок уведомлений
- Мини-смета
- Рекомендованные подрядчики

## 4. Модальные окна
- Вход/Регистрация — стеклянная модалка с формой (email + пароль, без реальной авторизации)
- «Зарегистрируйтесь» — при попытке гостя использовать ограниченные функции (3D генератор, проекты)
- Тарифы — таблица Freemium / Pro / Бизнес

## 5. Адаптивность
- **Мобильный**: левая панель → горизонтальная полоса внизу экрана, правый сайдбар скрыт, хедер с гамбургером
- **Планшет**: 2 колонки (лаунчер + центр), сайдбар по свайпу
- **Десктоп**: полный 3-колоночный layout

## 6. Футер
- `© 2026 StarTechPro — все права защищены!` по центру, внизу страницы

## 7. Анимации
- Smooth fade-in при переключении секций
- Hover-подъём плиток с glow
- Плавные переходы модалок (scale + fade)
